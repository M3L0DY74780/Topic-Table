Welcome to the Topic Table System

A shared experience where people can join a conversation, explore a topic, and connect with others through tablets, a hologram display, and a main server.

Tablet

Each user can log in using face recognition, view contact details, choose a topic, and use speech or translation support.

Main Server

The central system stores session data, manages activities, and helps the team control all tablets and hologram displays.

Go to Main Server

How the system works

  • Users arrive at a tablet and sign in securely.
  • The group selects a topic and starts a shared conversation.
  • The hologram display reflects the selected topic for everyone to see.
  • The main server stores the data for future sessions.
